# uxuipro

Skills **UI/UX Pro Max** pour Claude Code (installés via `ui-ux-pro-max-cli` v2.15.0, `uipro init --ai claude`).

## Contenu

`.claude/skills/` : `ui-ux-pro-max`, `design-system`, `design`, `brand`, `banner-design`, `slides`, `ui-styling`.

## Utilisation

- **Dans ce dépôt** : toute session Claude Code ouverte ici charge les skills automatiquement.
- **Dans un autre projet** : copier le dossier `.claude/skills/` à la racine du projet, ou lancer `uipro init --ai claude` dans ce projet.
- **Pour tous tes projets (sur ton ordinateur)** : `uipro init --ai claude --global`.
